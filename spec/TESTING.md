# 真機測試清單（Phase 14b）

網址：`https://frenemycards852.github.io`
每試一部機，影印或者複製一份下面嘅清單，逐項剔 ✅，有問題就寫 ❌ 同埋截圖。

**記低呢部機嘅資料：**
- 手機型號：＿＿＿＿＿＿（例如 iPhone 12、Samsung A54）
- 系統版本：＿＿＿＿＿＿（iPhone：設定 → 一般 → 關於本機；Android：設定 → 關於手機）
- 喺邊度打開：Safari ／ Chrome ／ WhatsApp 內 ／ IG 內 ／ Threads 內 ／ 主畫面 app ／ 電腦

有問題 send 俾 Claude 時，請講埋：**部機型號 + 喺邊度打開 + 做咗咩 + 預期見到咩 + 實際見到咩 + 截圖**。

## A. 開網
- [ ] 開網時見到鬼臉載入畫面，之後見到首頁
- [ ] 首頁 3 張卡飛入，下面有「點玩？」三步
- [ ] 向下捲，頂部欄變毛玻璃
- [ ] 撳右上角「English」，全部字變英文；再撳變返中文

## B. 整卡
- [ ] 撳「幫朋友整卡」，輸入名
- [ ] 揀類型（見到 6 個徽章）→ 揀男仔／女仔 → 揀角色（3 個場景）
- [ ] 貼相：揀相或者即刻影相，拖、放大、旋轉都郁得
- [ ] 分能力值 → 揀必殺技、特性、弱點 → 揀一句總結 → 檢查 → 完成
- [ ] 開卡包：沿虛線掃開，或者撳畫面任何位置
- [ ] 張卡背面出嚟，停一停再翻開，有光環
- [ ] 用手指向唔同方向拖張卡，見到卡背，放手會擺正
- [ ] 撳「分享」：WhatsApp 收到一張圖加一條連結（有真相會見到提醒句）
- [ ] 撳「儲存圖片」：相簿有張卡圖

## C. 收卡同反擊（要兩部機，或者 send 俾朋友）
- [ ] 喺 WhatsApp 撳朋友 send 嚟嘅卡連結，見到張卡（冇真相，係原本插畫）
- [ ] 撳「反擊」，整一張卡 send 返俾對方

## D. 挑戰同對戰（要兩部機）
- [ ] 卡簿 → 揀一張卡「用佢挑戰」→ 揀懲罰同戰術 → 整挑戰 → send 俾朋友
- [ ] 朋友撳連結 → 揀卡同戰術 → 開打
- [ ] 對戰：有 VS、叫聲泡泡、擬聲詞、血條殘影；必殺技有 Cut-in 橫額
- [ ] 最後有斜切 KO 或者計分，下面顯示邊個要受罰
- [ ] 朋友撳「send 結果俾佢」，你撳連結可以睇重播
- [ ] 「再戰！」可以再發挑戰

## E. 卡簿
- [ ] 卡簿見到所有整過同收到嘅卡，篩選掣撳得
- [ ] 撳一張細卡，大卡由佢個位放大出嚟
- [ ] 「整損友圖鑑」：揀幾張卡，砌出一張圖，可以分享
- [ ] 「匯出卡簿」：複製連結 → 喺另一個瀏覽器打開 → 匯入成功
- [ ] iPhone：卡簿有「iPhone 小貼士」

## F. 加到主畫面
- [ ] iPhone Safari：分享 →「加至主畫面」；Android Chrome：選單 →「加到主畫面」
- [ ] 主畫面 icon 係鬼臉卡，名係「損友圖鑑」
- [ ] 打開係全螢幕（冇網址列），頂部時間嗰度冇怪顏色
- [ ] 每一頁都可以撳左上角 icon 返首頁

## G. 特別情況
- [ ] 喺 WhatsApp／IG／Threads 入面打開，整卡同對戰都用得
- [ ] 手機設定咗大字體，版面冇爆、字冇重疊
- [ ] 手機開咗「減少動態效果」（iPhone：輔助使用 → 動態效果），全部嘢都仲用得
- [ ] 打橫部手機，都睇得到同用得到
- [ ] Samsung 或者開咗深色模式嘅手機，網站顏色正常（唔會變黑）

## 已知限制（唔係 bug）
- iPhone 嘅 Safari 同「主畫面 app」卡簿係分開嘅，要用匯出搬卡。
- 冇網絡時開唔到網站。
- 連結預覽（WhatsApp 嗰張圖）每條連結都係同一張，唔會顯示個別卡。
- 手指放喺大卡上面嗰陣唔可以捲頁面，要喺張卡以外嘅位置掃。
