# 插畫清單 · Frenemy Cards / 損友圖鑑

張卡唔再用程式砌頭像，改用插畫（2026-10-10 決定）。
每個類型 × 男女各一張，**總共 12 張**。張卡會根據「類型 + 男仔／女仔」自動用返對應嘅插畫。

---

## 1. 統一風格（12 張都要跟）

參考：`late-boy`（遲到系男仔，咬多士狂奔嗰張）。

- **日本動漫／漫畫插畫風**：粗而乾淨嘅黑色描線、賽璐璐色塊陰影、鮮艷色彩
- **有動感**：動作誇張、有集中線或速度線，表情搞笑誇張
- **角色**：年輕成年人（大約 18–28 歲）。每張係唔同嘅人，但畫風要好似出自同一個畫師
- **有背景**：背景要同類型主題有關，例如街道、辦公室、梳化
- **構圖**：直身，人物喺中間。**個樣同上半身要喺圖片上半部**（見第 2 節）

**唔可以有：**
- 任何**文字、字母、數字、招牌字、商標、品牌、浮水印、簽名**（AI 生圖好易出亂碼字，要特別留意）
- 現有動漫或遊戲嘅角色、服裝、招式，例如龍珠、海賊王、寵物小精靈
- 真實人物或者明星嘅樣
- 恥笑外表、身材、種族、性別、宗教、殘疾、健康；性感或者暴力血腥內容
- 只可以抽**生活習慣**（遲到、貪食、懶、工作狂、戀愛腦、串嘴）

| 項目 | 要求 |

| 格式 | JPG（或者 WebP），每張最好 **400 KB 以下**；太大我可以幫你壓縮 |
| 檔名 | `late-boy.jpg`、`late-girl.jpg`……（見第 3 節） |
| 放邊度 | 放喺 `docs/assets/cards/`，或者直接 send 俾我 |

```
┌───────────────────────────┐  0%
```

## 4. 如果用 AI 生圖工具：Prompt 範本

**每張都用同一段基本 prompt，**只改 `[ ]` 入面嘅內容，咁樣畫風會比較一致。
唔好喺 prompt 入面寫任何動漫、遊戲或者畫師嘅名。

**基本 prompt（英文）：**
```
Japanese anime manga illustration, bold clean black ink outlines, cel shading,
vivid colours, dynamic comedic action pose, exaggerated funny expression,
speed lines, a young adult [man / woman], [scene description],
knee-up or full body, character centred, face and upper body in the upper half
of the image, detailed background of [place], vertical portrait 5:7,
no text, no letters, no signs with writing, no logos, no watermark
```

**Negative prompt（如果工具有呢個選項）：**
```
text, letters, words, numbers, signature, watermark, logo, brand,
extra fingers, distorted hands, blurry face, real person, celebrity
```

**例子：late-girl**
```
... a young adult woman, sprinting toward a bus whose doors are closing while
applying lipstick, hair half tied, holding a takeaway coffee, an alarm clock
flying behind her, ... detailed background of a busy city street at morning ...
```

**整完之後檢查：**
- [ ] 冇亂碼字或者招牌字
- [ ] 手指數目正常，個樣清楚
- [ ] 個樣喺圖片上半部，冇俾左上角、右上角遮住
- [ ] 同 `late-boy` 放埋一齊睇，畫風夾唔夾
- [ ] 你確認嗰個工具嘅條款容許公開使用

## 6. 漫畫對戰用嘅姿勢圖（之後補畫）

漫畫對戰（預覽：網址加 `?comic=1`）而家用卡面插畫加動畫。每張插畫補畫 3 個姿勢之後，就會正式改用漫畫對戰。

| 姿勢 | 檔名例子 | 內容 |
|---|---|---|
| 攻擊 | `late-boy-attack.jpg` | 衝前出招，表情好兇或者好得意，配埋類型道具（例如遲到系揸住鬧鐘） |
| 中招 | `late-boy-hurt.jpg` | 被打中，身向後仰，眼凸或者冒汗 |
| KO | `late-boy-ko.jpg` | 倒低，✕✕ 眼，可以有啲星星喺頭頂轉 |

12 張插畫 × 3 = 36 張。可以一個系一個系咁做，未有嘅姿勢會自動用返卡面插畫。

**要求：**
- 同卡面插畫**同一個人物**：髮型、衫、顏色要一樣，畫風跟第 1 節
- **角色面向右邊**（右邊嗰位角色會自動左右反轉）
- **背景簡單**：淨色或者速度線就得，唔好有街景，因為兩個角色會疊埋一齊
- 角色佔畫面大部分，頭喺上面三分一
- 尺寸同第 2 節一樣：1080 × 1512，JPG，400 KB 以下
- 唔好有字

做好之後放喺 `docs/assets/cards/`，或者直接 send 俾我。我會喺 `types.json` 加：
```json
"poses": { "boy": { "attack": "assets/cards/late-boy-attack.jpg", "hurt": "...", "ko": "..." } }
```

## 7. 第二批角色：每個類型多 2 個場景（24 張）

每個場景畫**男仔**同**女仔**各一張。檔名：`late-boy-2.jpg`、`late-girl-2.jpg`、`late-boy-3.jpg`、`late-girl-3.jpg`……（`-2` 係場景 A，`-3` 係場景 B）。

### 因為用家會貼真人相上個頭，個頭一定要清楚

**每張整完都要檢查：**
- [ ] 塊面**向前**或者**微微側**（四分三角度），兩隻眼都見到
- [ ] 個頭**冇俾任何嘢遮住或者掂到**：手、食物、手機、杯、帽、兜帽、眼鏡、遮臉嘅頭髮、對話泡泡、蒸氣、特效
- [ ] 個頭**大致企直**（斜唔好超過 15 度）
- [ ] 成個頭喺畫面入面、喺圖片**上半部**，但**唔好貼近左上角同右上角**（張卡嗰兩個位有類型圓章同稀有度牌）
- [ ] 個頭唔好太細：大約係圖片闊度嘅 1/6 至 1/4
- [ ] **只有一個主角係大嘅**；朋友或者路人明顯細過主角，而且唔好喺主角個頭附近
- [ ] 第 1 節嘅規則照用：冇字、冇真人、冇武器，只抽生活習慣

**每個 prompt 都要喺第 4 節嘅基本 prompt 後面加：**
```
face clearly visible and facing the viewer, nothing covering or touching the head or face,
no hat, no hood, no glasses, hands kept away from the face, head upright,
the main character is clearly bigger than anyone else
```
